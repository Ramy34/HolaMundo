# 🌍 Hola Mundo

La finalidad de este repositorio es recopilar los programas básicos de "Hola Mundo" en los diferentes lenguajes de programación que voy aprendiendo. Este proyecto sirve como una referencia personal rápida de la sintaxis básica y la configuración inicial de distintos entornos.

## 🚀 Lenguajes Incluidos

*(Nota: Actualiza esta lista con los archivos y lenguajes reales de tu proyecto)*

- 🐍 **Python** (`hola_mundo.py`)
- ☕ **Java** (`HolaMundo.java`)
- 🟨 **JavaScript** (`hola_mundo.js`)
- ⚙️ **C++** (`hola_mundo.cpp`)

## 🛠️ Cómo ejecutar

Cada lenguaje requiere su propio entorno de ejecución o compilador. Asegúrate de tener las herramientas necesarias instaladas (por ejemplo, Node.js para JavaScript o el JDK para Java) antes de ejecutar los archivos.
